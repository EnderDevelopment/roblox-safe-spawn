# SafeSpawn

SafeSpawn is a Roblox script designed to provide spawn protection for players, ensuring they spawn in safe areas or under specific conditions. This script is ideal for game developers who want to control player spawns and prevent them from spawning in hazardous or restricted zones.

## Installation

1. Open Roblox Studio.
2. Create a new script or open an existing one.
3. Copy and paste the contents of `SpawnProtection.server.lua` into the script.
4. Place the script in the `ServerScriptService` folder in the Roblox Studio hierarchy.

## Use

1. Set the `spawnLocation` variable to the desired spawn location for players.
2. Adjust the condition in the spawn protection logic to match your specific requirements.
